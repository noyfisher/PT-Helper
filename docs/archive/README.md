# Archived documentation

Everything in this directory is a **historical, point-in-time record**: what was
true on the day it was written, on the branch it was written against. It is not
maintained and it is not a source of truth.

Do not edit these files to "fix" them — a stale audit that has since been acted
on is still an accurate record of the audit. If something here contradicts the
code, the code wins; update the living docs (`README.md`, `CLAUDE.md`,
`CONTRIBUTING.md`, `ios/LAYOUT.md`, `functions/README.md`, `scripts/README.md`)
instead.
