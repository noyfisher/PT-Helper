# UX Audit Report — 2026-05-20

## Summary
- **Screens audited:** 11 (Assess, My Plan, Rehab Plan Detail, Guided Workout, End Workout Dialog, Progress, Settings, Body Map, Medical Disclaimer, Pain Assessment, Wellness Goal Picker)
- **Total issues found:** 42
- P0 Critical: 0 | P1 High: 4 | P2 Medium: 17 | P3 Cosmetic: 21

**Overall Rating: 6.5 / 10**
The app has a clear and confident visual identity in its dark/red branded sections (main tabs, guided workout), but suffers from significant style fragmentation between the "main" UI and the "flow" UI (body map, pain assessment, wellness picker). Placeholder icons (`[?]`) appear across 5+ screens and should be treated as a release-blocking polish issue. Several design token violations undercut the brand, and a handful of functional UX problems (invisible disabled state, exposed delete buttons, debug items in production settings) need addressing before wide release.

## Recommended Fix Order

### P1 — Fix Before Next TestFlight (4 items)
1. **Settings — Debug tools visible** (issues 26, 27): Wrap `Export Debug Log` and `Session Events` in `#if DEBUG`. Verify the Release scheme excludes all debug rows.
2. **Progress — Always-visible delete buttons** (issue 17): Move to standard `swipeActions` + confirmation alert.
3. **Body Map — Invisible disabled Continue button** (issue 31): Apply visible disabled state styling.
4. **Wellness Picker — Custom goal input missing above fold** (issue 44): Surface the text field or add a visible scroll hint.

### P2 — Fix This Sprint (17 items)
Group by effort:
- **Quick token fixes** (30 min total): Purple icon → `AppColors.accent` (issue 18), chart axis → `AppColors.mutedText` (issue 19), End dialog color semantics (issue 16), edit button icon (issue 8)
- **Copy/title fixes** (1 hr): Nav title "Rehab Plan" → plan name (issue 7), nav title truncation on Wellness Picker (issue 42), disclaimer frequency (issue 38)
- **Navigation consistency** (half-day): Standardize nav bar style across flow screens (issues 9, 33), remove dual back buttons in body map (issue 32)
- **Pain Assessment selection** (half-day): Add background fill to `optionCard` selected state (issue 39)

### P3 — Cosmetic Polish (21 items)
Good candidates for a focused `/improve ux` pass:
- Replace all `[?]` placeholder icons (issues 1, 22, 23, 36)
- Remove leaf decorations or replace with on-brand treatment (issue 40)
- Fix double-labeling on Pain Trend and Recovery Insights (issues 20, 21)
- Progress bar upgrade (issue 41)
- Region chip scroll fade (issue 34)
- Weekly calendar number explanation (issue 11)
