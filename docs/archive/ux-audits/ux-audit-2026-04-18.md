## Global Observations

- **P0 Touch Targets.** Several buttons with explicit small frames (28×28, 32×32) fall below the 44pt HIG minimum: `ProgressTab.swift:237`, `RehabPlanView.swift:570`. These affect core flows (deleting a session, swapping an exercise) — highest priority.
- **P0 Accessibility.** Icon-only buttons without labels show up in `AnalysisResultView.swift:163`. Audit other icon-only `Button`s (ProgressTab chart controls, BodyMap3D hint button) for the same pattern.
- **P2 Font Drift.** Widespread use of raw `.system(size: N)` for display text (sizes 36–60pt) instead of `AppFonts` tokens — especially in workout/insights views.
- **P2 Padding Drift.** Numeric literals `4, 5, 8, 10, 20, 32, 52` appear instead of `AppSpacing.xs / .sm / .md / .lg / .xl / .xxl` in at least 7 files.
- **P2 Card Styling.** `ProgressTab` and a few cards in Settings manually assemble `background + cornerRadius + shadow` instead of using `.cardStyle()`.
- **P1 Dismiss Affordances.** Full-screen or sheet destinations (`DisclaimerView` in BodyMap3D, `GuidedWorkoutSummaryView`) don't clearly provide a close button — users could get stuck.
- **P3 Refactor Candidates.** `BodyMap3DView.swift` (1,189 lines) and `PainDetailView.swift` (990 lines) would benefit from extracting subviews.
